# Shipfolio logo kit — Leaf Launch (Aurora)

- `svg/` — masters: symbol (colour, small-size cut, black, white, blue, gradient cut-out), horizontal and stacked lockups (colour, reversed, black, white, blue), wordmark, app icons (dark, gradient, maskable), favicon, social image.
- `png/` — transparent PNG exports of the masters.
- `web/` — favicon set, touch and manifest icons, social image, `site.webmanifest`, `head-snippet.html`.
- `presentation.html` and `slides/` — the presentation board with in-use mockups.
- `GUIDELINES.md` — clear space, minimum sizes, colours, don'ts.

Wordmark: Inter Bold (SIL OFL 1.1), outlined. Not trademark-searched.
